# Support Scaling Requirements

## Requirements
- Target under 10 minutes support time per client per month
- No manual intervention workflows
- No customer-specific custom logic
- Self-serve only
- Automation default on
- Statuses must be explicit
- Repeated support issues must be fixed in product

## Launch Gates
- Confidence-based extraction + inline correction
- Visible reminder activity logs
- Zero-touch onboarding
- Explicit status language/tooltips
- No compliance advice decisions
- Track minutes per client per month
