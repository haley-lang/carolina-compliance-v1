# Setup Notes

## Stripe Payment Link TOS Checkbox

For each payment link (Crew, Foreman, General), add a TOS checkbox:

1. Go to Stripe Dashboard → Payment Links
2. Click on each payment link → Edit
3. Scroll to "Custom fields" or "Terms of service"
4. Add text: "I agree to the Terms of Service at carolinacompliancesolutions.com/terms-of-service"
5. Make it required
6. Save each link

This must be done manually in the Stripe dashboard.
